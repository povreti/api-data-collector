# Api Data Collector

A Python project that retrieves user data from an API, compares it with locally stored JSON data, and updates the file when changes are detected.

## Features

- Fetches user data from an API.
- Loads previously saved JSON data.
- Compares new and saved data.
- Updates the JSON file when changes are detected.
- Logs program events and errors.

## Teach Stack

- Python
- Requests
- JSON
- Logging

## Installation

pip install -r requirements.txt

## Usage

python main.py
